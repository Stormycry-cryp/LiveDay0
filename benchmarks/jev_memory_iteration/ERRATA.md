# 夹具勘误

## dev c01 来源支持标签过强

原文只明确从旧公寓搬入新租房、家具已送达，以及不再每天跨城通勤。提案 `goal_context` 额外写入靠近工作地点，该地点关系不能由原文严格推出。

模型把这个完整提案判为 `unsupported` 有证据依据。冻结标签预期 `supported` 过强，使该例混入夹具标注问题。本次原始 dev 结果保留为 7/8，不修改原 fixtures、hash、标签或报告，也不追改得分。

第一版 challenge 已真实执行，主代理报告原始结果为 4/6。该版已消耗，不重跑、不调整标签、不用新版本替换其结果。
