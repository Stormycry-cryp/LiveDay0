# 有界本机 CLI 规模基线

2026-10-11；Python 3.13.14、macOS 26.6 arm64、Homebrew PostgreSQL 17.10。仅合成夹具，零模型调用。此前160卡/Colima基线保留，不跨环境比较。

固定365与3650个生活事件，分别约为每天一件事的一年与十年。每事件2来源、2快照、3完成任务：小档730来源/730快照/1095任务，较大档7300来源/7300快照/10950任务。20%的预置快照保持active；每事件3个同调度键任务中仅最后一个是锚点。内容与时间确定，夹具通过受限应用角色直接SQL加载；不测试提取或写入质量。没有关系/派生/增量积压，不能代表它们的延迟。

默认入口**总是新建**标记空实例、0700私有Unix socket、禁止TCP；忽略调用者环境和既有数据库URL，只显式构造干净进程环境。owner仅建立库/角色、迁移及隔离证明；应用登录无superuser/BYPASSRLS/建库/建角色/继承权限。两档使用同一新集群、不同租户，顺序累加，退出只停止新实例，保留数据与日志。

```bash
# 必须使用已有支持环境（Python3.13、psycopg、PG17）
uv run --python 3.13 --no-sync python benchmarks/bounded_local_scale/run.py
# 改动只涉及保留SQL时，仅复测两个保留入口
uv run --python 3.13 --no-sync python benchmarks/bounded_local_scale/run.py --retention-only
```

每路径一个新worker进程，在进程内调用实际`cli.main`：1预热、7次计时。保留统计分无年龄配置/显式30天窗口；召回分近期唯一cue/旧唯一cue/无关cue。计时包含CLI解析、连接、现有read-before-use检查和结果JSON编译，不含Python启动、import、SQL跟踪摘要和召回后显式释放。7次nearest-rank P95等于max，仅描述样本，不估计生产尾延迟。SQL计数为应用`Connection.execute`次数，不含事务管理隐式协议。保留沿用2000ms SQL时限，失败立即停止该路径；每worker全程45秒，父流程会杀死超时worker并停止新PG。未人为增加召回SQL deadline，也不宣称现有deadline全路径生效。

应用峰值为操作worker的`ru_maxrss`，含解释器/依赖与跟踪开销，给出import后峰值作为参考；不以峰值差冒充净分配。PG数字为每约50ms读取新postmaster及其后代的RSS总和峰值：共享页会重复计数，采样可能漏短峰值，不是私有/独占内存。较大档PG值包含已加载的小档租户与缓存；不能当独立3650档内存。不可读采样报告null/错误次数，不能当0。初版运行各路径PG读数均非零，后续脚本补齐不可读标注，无需重复已有效测量。
