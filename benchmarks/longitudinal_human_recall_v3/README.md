# Longitudinal human recall v3

This directory is governed by `docs/benchmarks/v3-longitudinal-human-continuity-contract.md`.

Current state: `NO-GO_SOURCE_GATE`.

The reviewed source set does not yet contain the required three independent eligible families, two non-education longitudinal public-text families, or Chinese/English/Spanish source-authored evidence. OULAD is eligible only as an education-behavior supplement capped at 20%; it is not a life-continuity corpus.

Therefore this directory contains only the source decision matrix. There is no downloaded or frozen source data, no subject/case artifact, and no v3 RED run. Generated queries, translations, perturbations, or labels must never be used to fill those gaps.
