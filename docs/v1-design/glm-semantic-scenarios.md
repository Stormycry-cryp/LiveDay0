# GLM 完整提案合成语义验收

2026-10-11。本验收把人工编写的完整模型响应送入 127.0.0.1 假服务，经过实际 GLM adapter、ProposalBatch 解码、来源校验和保存前 gate。只检查提案语义在这段链路中的保留与路由，没有数据库写入或真实模型调用。

```sh
python3 -I -S -B tests/test_glm_semantic_scenarios.py -v
```

测试只加载标准库支持的合同与适配模块，避开产品包初始化和 pytest 数据库 fixture。可独立运行，不需要凭据、数据库或原一次性试验材料。

12 个定向测试覆盖改期前后日期及待确认未来、尚未行动的内心转折、普通生活片刻、条件偏好、明确边界、带触发条件的未来计划、敏感来源确认、引用/假设/第三方/不确定/禁止保存、纠正/反证/补充/遗忘意图、含 emoji 的 Unicode 局部来源绑定、空技术提案，以及类别与卡片类型冲突拒绝。通过时逐项比对正文、时间、来源与生产者；可接受提案也仍是候选，敏感、纠正与遗忘不会获得自动保存权限。

响应是人工固定的期望值。这些测试不能证明模型能从自然语言产生正确提案，不能证明示例/技术文字会被真实模型正确识别，也不替代存储、检索和删除端到端验收。现有完整合同仍最多输出一条提案；关系记忆、生活线索及更长上下文质量也尚未验收。
