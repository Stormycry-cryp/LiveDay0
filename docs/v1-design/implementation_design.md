# LiveDay0 v1 实现设计

## 目标与非目标

v1 要跑通一条可编码、可验收的生活记忆纵向闭环：生活证据／普通痕迹进入规范事件或少量明确事实，再形成当前状态、开放未来、基础生活线索与关系承诺，最终编译为正确、完整、紧凑的模型侧上下文。主要验收对象是记忆上下文，不是检索 Top-K 或最终回复。（I9、I10）

实现形态是服务器多用户的模块化单体；PostgreSQL 是唯一权威存储，pgvector 与全文索引只发现候选，关系邻接先由关系表承载。所有读写、关系、任务、缓存和索引都由服务端建立且强制携带不可变租户作用域。（I5–I7）

v1 不做业务回复策略、通用知识库、provider／SDK 平台、独立图数据库、SQLite、多 Agent 拓扑、每层公共 CRUD、完整人生章节、成熟慢速人物假设或复杂召回反馈。记忆层只供应理解材料，不决定语气、话术、追问或是否提及记忆。（A13、I8、I9）

## 最小模块

1. **证据接入**：校验服务端租户、接受文字／图片来源引用、生活相关普通痕迹、追加纠正／替代和删除请求；不允许静默覆盖来源。（A3–A5、A13）
2. **规范语义核心**：维护事件快照、待吸收事件增量、明确事实与前瞻事项；外部不能直接 CRUD 这些对象。（A11–A13、I1–I4）
3. **投影与关系**：维护当前状态、基础生活线索、重要关系视图及少量稳定类型的关系；投影引用规范锚点，不复制发生过什么。（I9、I12）
4. **维护调度**：确定性标脏、同目标合并、版本检查、重试、验证和原子替换；模型只重综合被限定的单个事件或视图。
5. **召回编译**：在一个固定快照内完成多路候选发现、有界关系展开、局部语义选择、规范身份去重、完整卡片编译和按需展开。（I10、I11a、I13）

模块共享 PostgreSQL 事务、租户守卫、来源／版本／生命周期、依赖失效和任务基础设施，但各自保留写入所有权；逻辑分层不自动变成服务、数据库或重复框架。（I5、I7、I12）

## 规范数据契约

**来源层。** 证据保存不可变内容或可追溯对象引用、模态、发生／接收时间和来源类别；图片的可观察内容、发送语境与模型解释分开，caption 仅是可重建索引。普通痕迹是有证据引用、低可访问、尚未事件化的生活观察，可后来参与事件重构，但不能直接生成推断性生活线索或慢速结论。（A3、A9、A10）

**共享小型外壳。** 每个规范卡片或派生视图只共享：服务端租户、规范身份与类型、生命周期／认识状态、有效时间、当前版本、来源或支持引用、依赖引用，以及 `supersedes`／`invalidates` 等失效关系。更新以期望版本防并发覆盖；规范身份去重，不靠生成文本相似度。候选指代与规范绑定分开，候选可以排序但绑定必须可逆。（A7、I11、I12）

**类型化主体。** 主体不是巨型字段表，而是各类型最小语义闭环：（I11、I11a）

- **事件**：目标与情境、关键经过／阻碍、因果转折、当前结果或状态、未完成未来、必要边界与不确定性；稀疏事件可为暂定态，未知保持未知。
- **明确事实**：来源支持的命题、适用对象／情境、当前有效性与边界；健康事实、明确偏好或决定不伪装成事件，也不从一次表达外推永久人格。（A11、A12）
- **前瞻事项**：等待／承诺／开放问题、触发条件或预期窗口、当前状态及其事件／事实／关系引用；结果出现后关闭并反馈相关事件重构。（I9）
- **派生视图**：视图类型（当前状态、生活线索、关系或后续慢速理解）、适用范围、引用的规范锚点、当前状态；有推断时另列支持、反例与认识状态。v1 只要求基础线索和关系承诺，不要求完整章节或成熟慢速画像。（I9、I12）

事件快照与未吸收增量分开保存。增量只描述一次有来源的局部变化及其影响范围；读取时可与快照合成一张带规范版本、增量来源和 `pending` 状态的完整有效事件卡，但不把该卡持久化为新规范版本。纠正、冲突或因果重排无法安全覆盖时必须先追平规范事件。（I1、I3、I4）

关系只采用小型稳定语义族：证据支撑、时间／因果、事件—线索组织、状态／失效、情境参与。类型、来源、生命周期、关系强度分别表达；向量相似只发现候选，不能合并事件或身份。（A7）

## 在线路径

1. 服务端建立租户上下文并验证所有对象引用同租户；任何仅凭全局 ID 的无作用域访问都拒绝。（I6、I7）
2. 在事务内保存证据／痕迹。明确纠正、删除或边界变化先记录关系并立即使已知错误卡、缓存与候选失效；普通生活变化只追加有界事件增量与受影响范围，不逐消息重写完整事件。（A4、A5、I1）
3. 固定本次理解周期的兼容快照。硬失效若命中已固定内容则废弃快照并重新获取；并发慢速更新不得混入半套新版本。
4. 在一次有界召回周期内并行形成语义／图片、全文、时间、实体、状态和开放回路种子；确定性外壳沿允许的关系族补齐小型候选，模型只在该包内做一次局部语义选择。（I13）
5. 对命中的待合并事件生成完整有效卡；若覆盖不安全则执行读前追平。随后按规范身份去重并编译短而完整的分层上下文，交给 Agent 推理层。（I2、I3、I11a）

在线路径同步保证“证据已收下、已知错误不再出现、当前上下文可用”，不等待生活线索或其他高层全部更新；原则上在线语义处理最多一次有界调用。（I13、I14）

## 后台维护

调度外壳根据新增、纠正、删除、身份重绑和规范版本变化确定性标记受影响目标；同租户同目标任务合并，携带基准快照版本，支持幂等重试。无既有目标的新材料只进入一个通用候选发现入口，快速路径不发明任意高层结构。

事件在意义边界、合并后的安静期或读前需要追平时重写。模型只读取当前事件快照、未吸收增量及必要证据，输出一个完整新主体；验证来源存在、版本匹配、未删除／未被推翻后，事务性替换快照并标记增量已吸收。失败保留未吸收日志并重试，不重扫整段会话，也不采用全系统事件溯源。（I2–I4）

生活线索、关系与后续慢速视图只消费规范事件和明确事实。每次仅以当前视图、新／变材料及必要支持和反例重综合一个受影响视图，通过校验后完整替换；失败时保留仍有效的上一版，不触碰无关邻域。（A10、A11）

## 召回与上下文预算

活跃生活线索是默认导航而非门禁：强烈当前线索可直接唤醒休眠事件或新人物，再反向恢复关系。召回不等于重新激活；只有该材料重新影响当前状态、选择、关系、目标或开放未来时，线索才回到活跃集合。

一次有界召回先准备活跃线索／直接种子、会改变当前理解的有界关系分支和事件索引；高连接人物／地点不自动扇出，重事件主体与原始证据仅按理解需要展开。模型可加深明确节点，不能扩大为全图漫游。（I13）

上下文按语义层和认识状态组织，但不强制填满。当前状态、开放未来、明确边界优先取得入场权；每个规范身份只出现一张完整卡，其他位置用引用表达跨层角色。卡片必须包含理解所需的类型、状态、时间／范围、来源、不确定性或失效限定和未完成未来。（I10、I11a）

单卡与整包都有硬预算。超量时先把卡片重写为更短但语义闭合的表示；仍放不下则整卡省略并保留可展开引用。绝不截断半个结论、孤立关系、无适用状态的假设或无不确定标记的候选。历史没有足够相关项时允许为空，不用最相似内容填充。（I11a、I14）

## 纠正删除与降级

纠正采用追加证据和显式替代／推翻关系：立即排除已知错误的事件、事实、关系、缓存和当前快照，再由规范核心统一重写受影响事件并局部重综合下游；原始证据不因旧解释错误而被改写。身份误合并则重绑证据、停用污染结论并只修复依赖邻域。（A4、A5、A7）

自然遗忘只改变各层可访问性；纠正保留来源与变化；明确删除则跨证据、身份、关系、索引、缓存、排队任务和派生视图传播。删除后仅允许无内容的最小防复活标记，不能把内容藏在低可访问状态或纠错历史中。

维护、索引或召回部分失败时，先排除任何已知被纠正、删除或越界的内容；继续使用当前证据、仍有效明确事实、开放事项和未受影响的最新有效完整卡。相关历史可为空，在线响应不等待修复；**缺少历史优于错误历史**。（I14）

## 实现顺序

1. 建立租户守卫、证据／痕迹、来源与版本／失效基础，证明所有路径无跨租户裸 ID。（I6、I7）
2. 建立事件、明确事实、前瞻事项、事件快照＋增量日志和完整有效事件卡。（A11、I1–I4、I11）
3. 建立纠正、身份候选／重绑、依赖失效与删除传播；先保证错误不会继续被读。（A4、A5、A7、I14）
4. 建立多路候选、关系族、有界召回、快照固定、规范去重与分层上下文编译。（I10–I13）
5. 建立事件追平与基础线索／关系视图的确定性调度、局部重综合、校验和重试。（I2、I9）
6. 用七个验收场景逐项验证规范变化、上下文与禁止结果，再基准测试未决参数；人生章节与成熟慢速理解继续后置。（I9、I10）

## 未决参数

下列仅为实现起跑用的**建议初值，全部待真实样本与基准测试**；它们不改变上述语义边界。（I2、I11a、I13）

| 参数 | 建议初值（待实测） | 主要观测 |
|---|---:|---|
| 单张完整卡片上限 | 180 tokens | 限定信息完整率、压缩后歧义 |
| 整包上下文上限 | 1600 tokens | 相关卡覆盖、噪音、模型延迟 |
| 初始候选／关系展开／最终入包 | 48／24／12 项 | 召回遗漏、重复与长尾延迟 |
| 每个关系族展开上限 | 6 项 | 高连接节点扇出与漏召 |
| 事件安静期 | 60 秒 | 重写次数、连续交流新鲜度 |
| 单事件待合并增量软上限 | 8 条 | 临时合成可靠性、追平成本 |
| 在线记忆调用超时 | 800 ms | 降级比例、端到端响应延迟 |
| 派生视图目标陈旧窗口 | 15 分钟 | 当前理解偏差、任务积压 |
| 普通痕迹准入与可访问性衰减 | 不设固定类别；先采软信号 | 后获意义召回率、隐私与存储量 |

任何实测调整只能改变容量、调度和候选范围，不能允许半卡、已知错误历史、跨租户访问或模型自由全图遍历。
