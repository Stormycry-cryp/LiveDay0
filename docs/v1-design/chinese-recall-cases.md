# 固定中文生活查询验收

本批接续原实用长期记忆计划第三优先，基线`6b2942d`。既有中文关键词、过敏与社交边界、歧义候选和幂等测试复用；只补候选包内完整口语问句的真实缺口。没有全仓重审或模型调用。

## 预先冻结的期望

[固定夹具](../../tests/fixtures/chinese_recall_cases.json)包含4个近期合成事件：跨城搬家与通勤变化、探望母亲、同城市观影、未付款且日期未定的陶艺课意向。10个查询在首次执行前经独立只读预检并冻结，SHA256为`7f2ebcf4fa771894213edb5ea8a1c4eafa65a66dbae867ec964ef49c84539831`，执行后未修改。

| 分类 | 查询/预期 |
|---|---|
| 应召回 | 搬家明确线索、带口语外壳的搬家/通勤/探望问题，各只带回对应事件 |
| 不应召回 | 同城市足球门票、手机升级，不插入这些生活历史 |
| 重复 | 同一搬家请求重放3次，只有一个规范身份、一个来源 |
| 证据不足 | “那次出门”保留两个人工预置候选且unbound；独居偏好没有支持则无历史；陶艺课仍为candidate，尚未付款、日期待确认 |

探望查询即使问“对我的影响”，也只提供已知探望，不补造影响。课程边界包含否定语句“不是已参加课程”，不能用全文子串断言误判为肯定发生。重复项是同请求重放，不证明不同输入自动语义合并；歧义候选人工预置，不证明自动发现指代。

## 反例和最小修复

基线8/10通过，搬家与探望的完整口语问句漏召回。现有中文bigram评分要求匹配超过整段问句的一半，明确生活线索被问句外壳稀释。

只在原相关性为0时，补连续4个汉字片段的词面匹配回退，分数上限2，保留原候选/租户/生命周期/出处/分层/快照门禁。没有测试词典、生活规则或特定事件分支。单一城市的两个字不会因为这条回退成为强线索。该回退也用于原相关性调用的派生/mention筛选，因此另定向检查既有生日与行业边界、过敏无关查询及空/英文cue。它只提供可能相关材料，不确认事实、激活线程、绑定人物或生成因果/性格解释。

最终相同期望10/10通过，8个无I/O词面控制断言通过。原事件body逐项不变、出处和边界/不确定性保留、重放后4张卡/5个来源、召回周期显式释放。默认完整预算与deadline仍沿上一批合同，本批没有重新测其已经通过的超时场景。
