# Jev 记忆判断自迭代

2026-10-19。当前版本已把个人工作经历纳入事件，移除置信度阈值，并完成真实 BeatAPI 判断、保存、事件追加、重放和召回的小规模闭环。全新第二版挑战为 6/6；这不是总体准确率或生产质量承诺。

## 发现的问题与改动

首版把 technical/project content 列为范围外，实际会排除个人工作经历。模型也收到完整提取合同，包含来源 UUID、哈希、提取器版本、候选自报置信度和保存标记；这些内容由代码校验即可，不应混入来源含义判断。

当前状态只包含选中原文、必要的周边上下文、时间参照，以及待记内容的类型、正文、适用范围和时间。工作任务、评审、发布、合作、冲突、处理事故及其影响都能成为事件；纯教程、代码或资料本体仍排除。

按用户要求，所有语义选择直接采用概率最高的选项，没有 0.8 门槛。无法确定、范围外、不使用本身仍是选项。confidence 不控制写入或召回，来源、授权、删除和版本规则继续由代码负责。

第一轮仍发现了同一协作后续被另开事件、例行日常被当成完整事件的问题。第二轮改成逐个候选比较同一事件/不同事件/无法确定，结果改变可属于原事件的进展；没有候选时由代码新建。普通例行琐事允许保留轻量痕迹，无须为每段叙述创建事件。召回也逐条选择使用/不使用/无法确定，支持多项和空结果。

## 真实对照结果

全部材料均为本次新写的虚构中文，完整语义提案为固定夹具。开发集、两版挑战在各自模型运行前绑定字节 hash。多例批量请求中的每题明确限定所属 case；预期标签没有发给模型。

| 版本与材料 | 符合冻结预期 | 工作事件路由 | 说明 |
|---|---:|---:|---|
| 首版输入 + 0.8，8 条开发材料 | 2/8 | 0/3 | 工作事件均进入待审阅 |
| 同一首版响应离线改为最高概率 | 3/8 | 0/3 | 零新调用；旧问题仍把三条工作事件归为范围外 |
| 第一轮：精简状态、中文问题、最高概率 | 7/8 | 3/3 | 已有事件进展、同项目不同经历均区分正确 |
| 第一版全新挑战 | 4/6 | 1/2 | 暴露协作后续与普通日常粒度问题，结果保留 |
| 第二轮逐候选比较，原开发材料 | 7/8 | 3/3 | 没有改写原标签以追求满分 |
| 第二版全新挑战 | 6/6 | 2/2 | 逐候选比较、痕迹、范围外和错误提案均符合预期 |

开发集 c01 的提案额外写入靠近工作地点，原文只明确搬家、家具送达、不再每天跨城通勤。模型判为缺少来源支持合理，原冻结标签的期待过强。原始得分仍保留 7/8，不调整分母或事后改标签，详见 [夹具勘误](../../benchmarks/jev_memory_iteration/ERRATA.md)。

第一版挑战在出结果后用于诊断第二轮问题，已成为已见材料；它不能证明第二轮的独立质量。第二版是另外六条前瞻冻结材料，只调用一次，不覆盖第一版失败。开发、挑战、重放口径及逐例选择和概率见 [完整结果](../../benchmarks/jev_memory_iteration/results.json)。

这些比较同时改变了输入和采用策略，不能把全部改善归因于 prompt。离线最高概率对照只说明移除阈值本身没有修好工作范围问题。开发集来源支持断言和首版拒绝理由也存在严格计分差异，不能把旧版某项计分失败解释为实际已发生误写。

同一开发批次，模型状态体积从 16,580 降到 4,418 bytes；第二轮总请求从 75,405 降到 68,414 bytes。但中文问题的 token 成本不同，整批 input tokens 从 22,757 变为 23,561，不能宣称 token 消耗下降。每批 usage 只计一次；离线重放的旧 usage 不计新消耗。

## 真实单例入库闭环

另用真实 `JevHTTP → MemoryJudgments → MemoryService`、独立 UTF-8 PostgreSQL 17 测试库验证，未使用模型响应夹具。输入取自已见开发材料，验证的是单例实际执行，不能再算一份独立质量样本。提取器仍提供固定来源绑定提案。

| 操作 | 实际结果 |
|---|---|
| 保存个人主持项目评审、决定延期并协调排期的经历 | `stored/new_event`，1 份来源、1 张事件卡 |
| 重复同一来源请求 | `duplicate`，没有新模型调用 |
| 保存同一评审事件后续协调进展 | `stored/existing_event`，匹配正确宿主 ID；仍为 1 张事件卡，新增 1 条增量 |
| 询问延期原因和需要协调的工作 | 选中已保存工作事件，保留来源；排除无关阅读经历 |

共三次真实模型调用，单次网络/解析时间约 0.96–1.18 秒；免费账号的调用间隔另计，测试按限流安排了等待。它不是整个用户请求的延迟承诺。

## 回归与未确认

`uv build` 成功，独立测试库中可移植回归 **628 passed**。14 项旧机器绑定试验因历史合同哈希问题未计入通过数，未改哈希或恢复旧模型权限。客户端协议、来源完整性、工作范围、低 confidence 的最高概率选择、多/空召回、事件逐候选比较、重放、更正、删除与租户隔离均有对应测试。

固定提案不证明生成式提取质量；批量问题与单例的上下文仍有差异。更多人物、长期候选发现、真实聊天分布和长期运行尚未验收。最高概率仍可能选错，有限材料不能证明普遍可靠；本次没有读取真实生活库、旧留出数据，也没有合并或部署。
